# @agenteam/ink-renderer

AgenTeam terminal renderer — Ink-based interactive agent conversation UI.

## What it does

- Renders agent conversation streams (user messages, assistant text, tool calls, thinking)
- Manages input state with paste-with-file-source support
- Slash command system with remote command suggestions
- Context bar, status layer, overlay system
- Scrollable virtual message list with draft persistence

## Dependencies

- `@agenteam/types` — shared protocol types and utilities
- `ink` / `react` — terminal UI framework
- `marked` — Markdown rendering
